## 📌 Tasks Completed

### 🎮 Task 1 — Number Game

A Java-based number guessing game in which the computer generates a random number within a specified range and the user tries to guess the number.

#### Features

- Generates a random number between 1 and 100
- Takes the user's guess as input
- Provides feedback if the guess is:
  - Too High
  - Too Low
  - Correct
- Limits the number of attempts
- Allows the user to play multiple rounds
- Displays the user's score

#### Concepts Used

- Java
- Random Number Generation
- Scanner
- Loops
- Conditional Statements
- User Input

#### Files

- `NumberGame.java`
- `Task1_NumberGame.mp4`

### 🎓 Task 2 — Student Grade Calculator

A Java program that takes marks obtained in each subject, calculates the total marks and average percentage, and assigns a grade based on the average percentage.

#### Features

- Takes the number of subjects as input
- Accepts marks for each subject
- Validates marks between 0 and 100
- Calculates total marks
- Calculates average percentage
- Assigns a grade based on the average percentage
- Displays the final result

#### Grade Criteria

| Average Percentage | Grade |
|---|---|
| 90 – 100 | A |
| 80 – 89 | B |
| 70 – 79 | C |
| 60 – 69 | D |
| 50 – 59 | E |
| Below 50 | F |

#### Concepts Used

- Java
- Scanner
- Loops
- Conditional Statements
- Type Casting
- Input Validation

#### Files

- `StudentGradeCalculator.java`
- `Task2_StudentGradeCalculator.mp4`

### 🏧 Task 3 — ATM Interface

A Java-based ATM simulation that allows users to perform basic banking operations such as checking balance, depositing money, and withdrawing money.

#### Features

- Check account balance
- Deposit money
- Withdraw money
- Validates transaction amounts
- Checks for sufficient balance
- Displays appropriate success and error messages
- Provides an exit option

#### Concepts Used

- Java
- Object-Oriented Programming
- Classes and Objects
- Methods
- Encapsulation
- Scanner
- Conditional Statements

#### Files

- `ATM.java`
- `BankAccount.java`
- `Task3_ATMInterface.mp4`
